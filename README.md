# Forensicfinders

Planning desk for the Keith Dean Fleming file and the A635 Holmfirth Road sight study.

It does not detect remains, and it does not write a find into a GPS or a drone file.

Wave numbers are a uniform plane wave in the host sand: phase velocity, attenuation, and a normal-incidence reflection. Conductivity is a stated textbook band, not a field sample. Road sight is terrain shielding on Copernicus GLO-30. A red cell is ground a 1.7 m eye on the road cannot see. It is not a grave.

```bash
npm install
npm run dev
```

The desk opens on port 8080.
