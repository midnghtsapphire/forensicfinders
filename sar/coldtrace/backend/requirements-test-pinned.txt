# WR #62 (follow-up to PR #60). Exact pins for the ColdTrace backend test run on CI.
#
# Why this file exists: requirements.txt cannot be installed on a plain CI image
# (gdal==3.13.1 and pdal==3.4.4 need native GDAL/PDAL builds), and requirements-test.txt
# leaves rasterio/numpy unpinned on purpose. So CircleCI job `coldtrace-pinned` installs
# THIS subset: every package the backend tests import, each pinned to the SAME version
# as sar/coldtrace/backend/requirements.txt. tests/test_sentinel_parser_consolidation.py
# fails if any pin here drifts from requirements.txt, and (COLDTRACE_PINNED_ENV=1, set only
# in that CI job) fails if the installed rasterio/rioxarray/xarray differ from the pins.
#
# Supported interpreter for these pins: CPython 3.12 (also 3.11; numpy 1.26.4 and
# rasterio 1.3.10 publish no wheels for 3.13+). Verified: 3.12.16, see docs/sensecrew/backscatter/LEDGER.md.
