# rasterio and numpy are deliberately NOT pinned here, although tests/test_sentinel_
# arrays.py imports both directly and requirements.txt pins them at rasterio==1.3.10
# and numpy==1.26.4. Neither of those versions publishes a distribution for Python
# 3.14, so pinning them here would make this file uninstallable on a current
# interpreter -- a certain breakage traded for a stated risk. The risk is real and is
# written down rather than hidden: the test stack can differ from production, and the
# NDVI tests were in fact verified on rasterio 1.5.2 and numpy 2.5.0. The underlying
# problem is that requirements.txt itself cannot be installed on Python 3.14, which is
# a pre-existing condition for the whole backend and needs a decision about which
# Python versions coldtrace supports. Pin these two the moment that decision is made.
